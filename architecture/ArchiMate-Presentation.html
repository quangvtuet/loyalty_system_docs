Cuộn chuột / Kéo thả

1. Cổng Ingress & Gateway

API Gateway Ingress kiểm soát lưu lượng, xác thực Token JWT và giới hạn Rate Limit 1.000 req/phút.

2. Nền tảng K8s Pods

5 Microservices đóng gói Container chạy trên Kubernetes Cluster, tự động mở rộng Pods (HPA) ≥ 500 TPS.

3. Middleware Kafka & Redis

Kafka Bus điều phối sự kiện giao dịch; Redis Cluster xử lý khóa phân tán Redlock và Idempotency.

4. CSDL Polyglot & CDC

PostgreSQL Database-per-Service + ClickHouse Data Warehouse đồng bộ thời gian thực qua Debezium CDC.
