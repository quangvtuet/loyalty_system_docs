Rendering PlantUML SVG...
Scroll to Zoom · Drag to Pan

1. Ingress & Security

Ingress Controller validates JWT, terminates SSL/TLS, and enforces 1,000 req/min rate limits.

2. Kubernetes Compute

5 Spring Boot Microservice Pods autoscaled via Horizontal Pod Autoscaler (HPA) to sustain ≥ 500 TPS.

3. Middleware & Cache

Kafka 3-Broker Cluster partitioned by member_id; Redis Sentinel provides Redlock and 72h idempotency key.

4. Polyglot Storage

4 PostgreSQL DBs for transactional isolation + ClickHouse Star Schema synced via Debezium CDC.
